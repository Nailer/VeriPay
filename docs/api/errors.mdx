## Envelope

```json
{ "error": "That seller link doesn't exist." }
```

Messages are written for end users and are safe to display directly.

## Status codes

| Code | Meaning in VeriPay |
|---|---|
| `200` | Success (including idempotent replays and "in progress" states) |
| `400` | Validation failed, wrong state, or verification failed |
| `401` | Not signed in (`Sign in first.`), bad signature, bad admin passcode, bad webhook signature |
| `404` | Unknown seller, intent, order, or subscription |
| `409` | Conflict: handle taken, account already has a link, order already moved on |
| `500` | Unexpected server error |
| `502` | Upstream failure after payment (mint failed — retryable), Paystack unreachable, reputation read failed |
| `503` | Storage not configured, pricing unavailable |

<Accordion title="In plain words" icon="lightbulb">
  Numbers starting with 2 mean it worked; 4 means something about the request was wrong; 5 means something went wrong on VeriPay's side or with a service it depends on.
</Accordion>

## Messages by route

### `/api/sellers`

| Status | Message |
|---|---|
| 400 | `Missing handle or address` |
| 400 | `Pick a link name of 3–30 letters, numbers, dashes or underscores.` |
| 400 | `Enter your shop name.` |
| 400 | `Invalid address.` / `Invalid request` |
| 401 | `We couldn't confirm you control that account. Try again.` |
| 409 | `This account already has a payment link.` |
| 409 | `That link name is taken — try another.` |
| 500 | `Couldn't save your link. Try again.` |
| 503 | `Storage isn't configured.` |

### `/api/pay/intent`

| Status | Message |
|---|---|
| 400 | `The minimum is ₦100.` · `The maximum is ₦5,000,000.` |
| 400 | `Say what you're buying, so you and the seller agree on it.` |

| 400 | `You can't pay your own link.` |
| 401 | `Sign in first.` |
| 404 | `That seller link doesn't exist.` |
| 500 | `Couldn't start the payment. Try again.` |

### `/api/pay/confirm`

| Status | Message |
|---|---|

| 400 | `Card payment was not successful (…).` |
