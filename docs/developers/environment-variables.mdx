<Note>
  Only variables prefixed **`NEXT_PUBLIC_`** reach the browser. Everything else is server-only. `.env` is gitignored — never commit secrets, and never print them in logs or chat.
</Note>

<Accordion title="In plain words" icon="lightbulb">
  These are the settings and secret keys the app needs. Ones starting with `NEXT_PUBLIC_` are visible to anyone's browser, so they must never be secret. The rest stay on the server.
</Accordion>

## Required

| Variable | Scope | Purpose |
|---|---|---|
| `NEXT_PUBLIC_CONTRACT_ADDRESS` | public | Deployed `VeriPayEscrow` (`0x00bdf9fb…1517e6d` on testnet) |
| `NEXT_PUBLIC_THIRDWEB_CLIENT_ID` | public | thirdweb client for sign-in and transactions |
| `SUPABASE_URL` | server | Your Supabase project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | **secret** | Service-role key; bypasses RLS — server only |
| `ADMIN_PASSCODE` | **secret** | Gates `/admin` and `/api/admin/*` (falls back to a hard-coded default if unset — always set it) |

## Pay links (card → naira → escrow)

| Variable | Scope | Purpose |
|---|---|---|
| `PAYSTACK_SECRET_KEY` | **secret** | Server-side verification. Without it, card flow runs in labelled TEST MODE |
| `NEXT_PUBLIC_PAYSTACK_PUBLIC_KEY` | public | Inline popup. `pk_test_…` shows the test-card hint |
| `PAY_MINTER_PRIVATE_KEY` | **secret** | Testnet-only key that owns vNGN, mints after verified charges, and sponsors gas. Falls back to `EXCHANGE_PAYOUT_PRIVATE_KEY` |
| `NEXT_PUBLIC_NGN_TOKEN_ADDRESS` | public | vNGN address (default `0xdbb53d0a…31eb`) |

## Network and indexing

| Variable | Scope | Purpose |
|---|---|---|
| `NEXT_PUBLIC_MONAD_RPC_URL` | public | RPC for client **and** server (e.g. Alchemy `https://monad-testnet.g.alchemy.com/v2/KEY`). Falls back to `https://testnet-rpc.monad.xyz`. Client-exposed by design — **restrict it to your domain in Alchemy's dashboard** |
| `MONAD_RPC_URL` | server | Optional server-only override |
| `ENVIO_GRAPHQL_URL` | server | Envio endpoint. Without it, reputation reads the chain |
| `NEXT_PUBLIC_AUSD_ADDRESS` | public | Override AUSD (default `0x333a12e2…463f`) |

## Push notifications

| Variable | Scope | Purpose |
|---|---|---|
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | public | Browser subscription key |
| `VAPID_PRIVATE_KEY` | **secret** | Server signing key |
| `VAPID_SUBJECT` | server | Contact URI (default `mailto:support@veripay.store`) |

Generate keys with `npx web-push generate-vapid-keys`. Without both, push silently no-ops.

## Exchange (pre-hackathon)

| Variable | Default | Purpose |
|---|---|---|
| `EXCHANGE_SPREAD_PERCENT` | `3.5` | Margin (clamped 0–25) |
| `EXCHANGE_NGN_USD_RATE` | — | Pin true cost of funds; overrides Bybit |
| `EXCHANGE_QUOTE_TTL_MINUTES` | `15` | Quote lock (1–120) |
| `EXCHANGE_MIN_NGN` / `EXCHANGE_MAX_NGN` | `1000` / `5000000` | Order limits |
| `EXCHANGE_MERCHANT_BANK_NAME` | — | Bank buyers pay into |
| `EXCHANGE_MERCHANT_ACCOUNT_NUMBER` | — | Account number |
| `EXCHANGE_MERCHANT_ACCOUNT_NAME` | — | Account name |
| `EXCHANGE_MERCHANT_ADDRESS` | — | Where sellers send crypto |
| `EXCHANGE_PAYOUT_PRIVATE_KEY` | — | **Secret** hot wallet; enables automatic MON delivery |

## Gotchas

<AccordionGroup>
  <Accordion title="Missing NEXT_PUBLIC_ prefix">
    Setting `CONTRACT_ADDRESS` instead of `NEXT_PUBLIC_CONTRACT_ADDRESS` silently does nothing for client code. This bug existed in production once.
  </Accordion>
  <Accordion title="Near-miss names">
    A past bug used `_ACCOUNT_NUMBER` / `_ACCOUNT_NAME` instead of `EXCHANGE_MERCHANT_ACCOUNT_NUMBER` / `EXCHANGE_MERCHANT_ACCOUNT_NAME`, which fell back to placeholder bank details shown to real buyers. If bank details look wrong, check exact names.
  </Accordion>
  <Accordion title="Local vs Vercel drift">
    `.env` and Vercel's environment settings (Production vs Preview) are separate and can drift. `veripay.store` currently serves the `hackathon/metropolis` branch as a **Preview** domain, so it uses **Preview** env vars.
  </Accordion>
  <Accordion title="Minter must own vNGN">
    If only `EXCHANGE_PAYOUT_PRIVATE_KEY` is set, that wallet must be made vNGN's owner and hold MON, or delivery fails after the card is charged. Check `GET /api/pay/intent`.
  </Accordion>
</AccordionGroup>
