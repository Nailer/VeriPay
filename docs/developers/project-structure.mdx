## Key Files Explained

### `src/app/layout.tsx`

The root layout wraps every page with:
- `Navbar` component for navigation
- `ThemeProvider` (next-themes) for dark/light mode
- `ThirdwebProvider` for wallet connectivity
- Global font and HTML structure

### `src/app/client.ts`

Initializes the singleton Thirdweb client used across the app:

```typescript
import { createThirdwebClient } from "thirdweb";

export const client = createThirdwebClient({
  clientId: process.env.NEXT_PUBLIC_THIRDWEB_CLIENT_ID!,
});
```

### `src/lib/abi.ts`

Exports two key values used throughout the app:

```typescript
export const escrowAbi = [...] as const;  // Full typed ABI
export const CONTRACT_ADDRESS = "0xd0cc...1621" as `0x${string}`;
```

### `src/components/Navbar.tsx`

The most complex component — handles:
- Wallet connection button (Thirdweb `ConnectButton`)
- Theme switching (Light / Dark / System)
- Notification bell with polling and unread badge
- Mobile responsive hamburger menu
- Notification panel with read/unread state

### `src/app/api/notifications/route.ts`

Next.js API Route Handler (App Router):
- `GET` — Fetch notifications by wallet address
- `POST` — Create a new notification
- `PATCH` — Mark all notifications as read

### `src/app/api/chat/route.ts`

Next.js API Route Handler:
- `GET` — Fetch all messages for a trade ID
- `POST` — Send a new message + trigger notification
