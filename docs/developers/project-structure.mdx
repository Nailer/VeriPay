## Where to change what

| I want to… | Edit |
|---|---|
| Change pay-link validation or limits | `src/lib/payments.ts` (`PAY_MIN_NGN`, `PAY_MAX_NGN`, `createIntent`) |
| Change gas sponsorship | `src/lib/payments.ts` (`GAS_FLOOR`, `GAS_TOPUP`, `MAX_GAS_TOPUPS`), `src/lib/gas.ts` |
| Change handle rules | `src/lib/sellers.ts` **and** `supabase/schema.sql` `CHECK` |
| Change reputation rules | `src/lib/reputation.ts` **and** `indexer/src/EventHandlers.ts` — keep identical |
| Add an escrow action | `contracts/VeriPayEscrow.sol`, `src/lib/abi.ts`, `src/lib/escrow.ts`, tests |
| Change consumer copy | `src/app/{pay,sell,orders,trade}/…`, `src/components/OrdersList.tsx` |
| Change the auto-release scan | `cre/auto-release/config.*.json` (`scanLimit`, `schedule`) |
| Add a docs page | `docs/*.mdx` + `docs/docs.json` navigation |
