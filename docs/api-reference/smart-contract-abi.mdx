## Usage Examples (TypeScript + viem)

### Setup

```typescript
import { createPublicClient, createWalletClient, http, custom, parseEther } from 'viem';

const MONAD_CHAIN = {
  id: 10143,
  name: 'Monad Testnet',
  nativeCurrency: { name: 'MON', symbol: 'MON', decimals: 18 },
  rpcUrls: {
    default: { http: ['https://testnet-rpc.monad.xyz'] },
  },
};

const CONTRACT_ADDRESS = '0xd0cc532f55ce6849d5b70e24d6188073f8921621';

// For reading (no wallet needed)
const publicClient = createPublicClient({
  chain: MONAD_CHAIN,
  transport: http('https://testnet-rpc.monad.xyz'),
});

// For writing (requires wallet)
const walletClient = createWalletClient({
  chain: MONAD_CHAIN,
  transport: custom(window.ethereum),
});
```

### Read Trade Data

```typescript
const trade = await publicClient.readContract({
  address: CONTRACT_ADDRESS,
  abi: escrowAbi,
  functionName: 'trades',
  args: [BigInt(0)], // Trade ID
});

console.log({
  buyer: trade[0],
  seller: trade[1],
  amount: trade[2],     // bigint in wei
  released: trade[3],
  refundApproved: trade[4],
  metadata: trade[5],
});
```

### Create an Escrow

```typescript
const hash = await walletClient.writeContract({
  address: CONTRACT_ADDRESS,
  abi: escrowAbi,
  functionName: 'createTrade',
  args: [
    '0x742d35Cc6634C0532925a3b844Bc9e7595f2bD18', // seller
    'iPhone 15 Pro Max, Lagos delivery',              // metadata
  ],
  value: parseEther('0.5'), // 0.5 MON
  account: '0xYourAddress...',
});

// Wait for confirmation
const receipt = await publicClient.waitForTransactionReceipt({ hash });
```
