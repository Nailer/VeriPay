## Design choices compared with typical crypto escrow

| Decision | Typical crypto escrow | VeriPay | Why |
|---|---|---|---|
| Onboarding | Seed-phrase wallet | Passkey (PRF) EOA | Target users have never held a seed phrase |
| Funding | User brings tokens | Card → server-verified mint | Users hold naira, not tokens |
| Gas | User pays | Capped server sponsorship | Users have no MON |
| Asset | Native coin | Any ERC-20 (vNGN, AUSD) or MON | Price stability between lock and release |
| Deadlock | Funds stuck | Dispute + arbitrator, auto-release | Liveness for both parties |
| Fee changes | Often apply retroactively | Snapshotted per trade, capped at 5% | Predictability |
| Reputation | Off-chain reviews | Event-sourced, indexer + chain fallback | Unfakeable trust signal |
| Upkeep | Manual "claim" | Chainlink CRE cron | Sellers never wait on a human |
