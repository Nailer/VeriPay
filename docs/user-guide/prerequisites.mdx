## What You Need

VeriPay is designed to be accessible to everyone — whether you're a crypto veteran or have never touched a blockchain before.

### Required

<CardGroup cols={2}>
  <Card title="A Web Browser" icon="globe">
    Any modern browser works: Chrome, Firefox, Safari, Brave, Edge, or Opera. Both desktop and mobile are fully supported.
  </Card>
  <Card title="An Internet Connection" icon="wifi">
    VeriPay is optimized for low-bandwidth connections. Even a basic mobile data connection is sufficient.
  </Card>
</CardGroup>

### Recommended (But Not Required)

<CardGroup cols={2}>
  <Card title="A Crypto Wallet" icon="wallet">
    MetaMask, WalletConnect, Coinbase Wallet, Rainbow, Rabby, or Zerion. **Don't have one?** No problem — you can sign in with email, Google, Apple, Facebook, or phone number and VeriPay will create a wallet for you instantly.
  </Card>
  <Card title="MON Tokens" icon="coins">
    You need MON (Monad's native token) to create escrows and pay gas fees. On testnet, you can get free MON from the [Monad Faucet](https://faucet.monad.xyz). See our [Getting MON Tokens](/user-guide/get-mon-tokens) guide.
  </Card>
</CardGroup>

### What You Do NOT Need

<Check>No bank account</Check>
<Check>No KYC documents (passport, ID, utility bills)</Check>
<Check>No minimum transaction amount</Check>
<Check>No app download — VeriPay runs entirely in your browser</Check>
<Check>No crypto experience — we'll guide you through everything</Check>

## Network Information

VeriPay currently operates on the **Monad Testnet**:

| Property | Value |
| --- | --- |
| Network Name | Monad Testnet |
| Chain ID | `10143` |
| RPC URL | `https://testnet-rpc.monad.xyz` |
| Currency Symbol | MON |
| Block Explorer | [monad-testnet.socialscan.io](https://monad-testnet.socialscan.io) |

<Info>
  If you're using MetaMask, VeriPay will **automatically add Monad Testnet** to your wallet when you create your first escrow. No manual configuration needed.
</Info>
