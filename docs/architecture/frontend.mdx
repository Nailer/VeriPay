## Navigation

Top bar: **My orders**, **Sell**, **Check a seller**; under **More**: **Pay with crypto** (`/create`), **Buy / sell crypto** (`/exchange`), **All trades** (`/dashboard`). The signed-in chip shows the shop name or **Signed in** — never an address or MON balance (`detailsButton.render`). Theme switcher: Light / Dark / System.

## Polling

All polling goes through `usePolling(callback, intervalMs, enabled)` (`src/lib/usePolling.ts`): runs immediately, pauses when the tab is hidden, fires once on return, and stops when `enabled` is false (e.g. a settled order).

| Where | Interval |
|---|---|
| Notifications bell | 20 s |
| `OrdersList` | 10 s (while any order is open) |
| Order / exchange chat | 4 s |
| Exchange order | 5 s (until settled) |
| Exchange rates (buy/sell) | 10 s |
| Exchange landing | 30 s |
| Admin visible tab | 8 s; open chat thread 4 s |

<Accordion title="In plain words" icon="lightbulb">
  The app refreshes information regularly, but only while you're looking at it, so it doesn't drain your battery or data in the background.
</Accordion>

## Transaction pipeline

Every write uses thirdweb's pipeline from `src/lib/monad.ts`:

```ts
import { prepareContractCall, sendTransaction, waitForReceipt } from "thirdweb";
import { escrowContract } from "@/lib/monad";

await readyToTransact(account.address);                     // gas sponsorship check
const tx = prepareContractCall({ contract: escrowContract, method: "releaseToSeller", params: [id] });
await waitForReceipt(await sendTransaction({ account, transaction: tx }));
```

<Warning>
  **Never use `window.ethereum`.** It only exists for browser-extension wallets; it's `undefined` for thirdweb in-app wallets, WalletConnect and passkey accounts. Using it produced "No browser wallet detected" for most mobile users until it was removed. See [Sending transactions](/developers/sending-transactions).
</Warning>

## Contract-version compatibility

`src/lib/escrow.ts` normalises v1 (6-field `trades()`) and v2 (12-field) into one `EscrowTrade` shape with a `legacy` flag, detecting the version by calling `feeBps()` (reverts on v1) and caching per address. **Always read via `readTrade()` / `readNextTradeId()`.** v2-only UI (report a problem, countdown, fee line, arbitration) is gated on `!trade.legacy`.

`formatTradeAmount(trade)` renders amounts by asset: vNGN → `₦25,000`, AUSD → `AUSD`, native → `MON`.

## Design rules

- **Strict black and white.** No accent colours; zinc shades; inverted for dark mode.
- `font-black` uppercase micro-labels with wide tracking; `rounded-3xl` cards.
- **Max 2–3 buttons per screen.** Obvious to someone who has never used crypto.
- **Mobile-first**, verified at 375 px.
- Motion via `globals.css` keyframes (`anim-fade-up`, `anim-scale-in`, `anim-shimmer`), respecting `prefers-reduced-motion`.

### Performance rules

- No large blurred layers or `mix-blend` + `animate-pulse`; ambient glow uses cheap radial gradients (`.bg-ambient`).
- Avoid `backdrop-blur-xl` on big cards.
- Animate `transform`, not `background-position`.
- No raw `setInterval` fetches; no full-page re-render per second for timestamps (the trade countdown ticks every 30 s).
