## Why This Stack?

### Next.js 16 + React 19

Next.js provides the **best developer experience** for building full-stack React applications:
- **App Router** — file-based routing with layouts and loading states
- **Server Components** — reduced client-side JavaScript for faster page loads
- **API Routes** — built-in backend for notifications and chat, no separate server needed
- **Automatic code splitting** — only loads the JavaScript needed for each page

### viem over ethers.js

We chose [viem](https://viem.sh) over the more popular ethers.js for several reasons:
- **TypeScript-first** — full type inference for contract interactions
- **Smaller bundle** — tree-shakeable, only includes what you use
- **Better DX** — cleaner API for `readContract`, `writeContract`, and `waitForTransactionReceipt`
- **Active development** — rapidly evolving with Monad compatibility

### Thirdweb v5

Thirdweb's wallet SDK is chosen specifically for **accessibility**:
- **Social login** — users can sign in with email, Google, Apple, Facebook, or phone
- **In-app wallets** — non-custodial wallets created automatically for social login users
- **10+ wallet options** — MetaMask, WalletConnect, Coinbase, Rainbow, Rabby, Zerion
- **ConnectButton** — drop-in UI component that handles the entire wallet connection flow

### Monad

Monad is the ideal chain for VeriPay because:
- **Speed** — 10,000+ TPS means escrow creation and settlement feels instant
- **Cost** — near-zero gas fees make micro-escrows economically viable
- **EVM compatibility** — works with all existing Ethereum tooling (MetaMask, viem, etc.)
- **Parallel execution** — transactions don't queue behind each other, no congestion
