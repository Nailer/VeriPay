| Layer | Technology | Version | Why |
|---|---|---|---|
| Chain | **Monad testnet** | chain `10143` | ~1 s confirmation, < ₦1 per tx, EVM-compatible |
| Smart contracts | **Solidity** | `^0.8.24` | Checked arithmetic; escrow has no imports, so it deploys straight from Remix |
| Web framework | **Next.js** (App Router) | `16.2.3` | Pages + API routes in one deployable unit |
| UI | **React** | `19.2.4` | |
| Styling | **Tailwind CSS** | `4` | Utility-first, strict monochrome design |
| Language | **TypeScript** | `5` | |
| Accounts | **Mera** `@category-labs/mera` | `^0.2.0` | Passkey PRF → signing key (Monad Foundation) |
| Key derivation | `@scure/bip32`, `@scure/bip39` | `^2.4.0` | Audited, dependency-free |
| Wallet SDK | **thirdweb** | `^5.119.4` | Uniform tx pipeline across in-app, injected, WalletConnect and adapted wallets |
| Chain client | **viem** | `^2.47.12` | Reads, server writes, signature verification, ABI coding |
| RPC | **Alchemy** Monad testnet | — | Reliable RPC; public node fallback |
| Indexer | **Envio HyperIndex** | hosted dev tier | Event handlers → GraphQL, HyperSync for Monad |
| Automation | **Chainlink CRE** `@chainlink/cre-sdk` | CLI v1.38.0 | Decentralised cron + signed reports |
| Card payments | **Paystack** | inline v1 + REST | Nigerian card acquiring |
| Database | **Supabase** `@supabase/supabase-js` | `^2.110.8` | Hosted Postgres, RLS |
| Push | **web-push** | `^3.6.7` | VAPID Web Push |
| Theme | **next-themes** | `^0.4.6` | Light/dark/system |
| Icons | **lucide-react** | `^0.479.0` | |
| Hosting | **Vercel** | — | Next.js native |
| Contract tests | **solc** + **Ganache** + Node test runner | solc `^0.8.30`, ganache `^7.9.2` | No Hardhat/Foundry needed |
| Indexer runtime | Node, pnpm, Docker (local) | — | Envio requirements |
| CRE runtime | **Bun** | — | Expected by the CRE compiler |
| Video tooling | Playwright, ffmpeg | — | Automated demo recording |

## Third-party code

- `contracts/cre/ReceiverTemplate.sol`, `IReceiver.sol`, `IERC165.sol` — copied **unmodified** from Chainlink's [`cre-templates`](https://github.com/smartcontractkit/cre-templates) (`starter-templates/keeper-bot`), MIT.
- **OpenZeppelin** `Ownable` — imported by the Chainlink template (MIT).
