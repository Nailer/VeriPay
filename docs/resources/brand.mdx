## The mark

A **check mark inside a rounded square** — "verified, settled". Source: `src/app/icon.svg`, `src/components/Logo.tsx`; full set (SVG + PNG: icon, mark, logo, square, on white/black) in `brand/`, generated by `brand/gen.mjs` and `brand/gen-square.mjs`.

## Colour

| Token | Value | Use |
|---|---|---|
| Black | `#000000` / zinc-950 `#09090B` | Primary, text, buttons |
| White | `#FFFFFF` / zinc-50 `#FAFAFA` | Backgrounds, inverted text |
| Zinc scale | zinc-100 … zinc-900 | Borders, secondary text, surfaces |

<Note>**Strict black and white.** No accent colours. The earlier pink `#FF007A` was deliberately removed.</Note>

## Typography

Inter (or system sans). Headings `font-black`; micro-labels uppercase with wide tracking.

## Usage

| ✅ | ❌ |
|---|---|
| Use on plain black or white | Recolour the mark |
| Keep clear space ≥ the check's stroke width × 3 | Stretch, rotate or add effects |
| Use the square icon for avatars | Use the wordmark smaller than 16 px tall |

## Writing about VeriPay

- Lead with **buyer protection**, not crypto.
- "Pay only when it arrives."
- Say **order**, **held safely**, **paid out** — not trade, escrow, wallet.
