<Update label="October 2026" description="Docs and submission">
  - **Documentation:** full Mintlify documentation site (this site) covering product, user guides, architecture, contracts, API, developers, security and resources.

<Update label="October 2026" description="Metropolis features">
  - **Proof page** — reads a transaction live from Monad and explains it in words.
  - **Order page and seller lookup** in plain language.
  - **Chainlink CRE workflow runs end to end** and released a real order (#2) on 11 Oct 2026.
  - **Plain-language navigation**, **My orders**, and fees covered for sellers.
  - Buyer gas top-up made **reliable and resumable** (fix for "insufficient balance" after paying).
  - Live **Envio indexer** endpoint recorded.
  - Proper **receipt** after a pay-link payment.
  - Card step no longer skipped when the Paystack public key is missing.
  - Repository renamed to `Nailer/VeriPay`; links updated; logo files added.
</Update>

<Update label="September 2026" description="Metropolis foundations">

  - **Contract suite** on a local EVM (30 tests) and an **end-to-end payment test**.
  - MIT licence, example env file and database schema.
  - **AUSD-extended escrow** deployed (`createTradeWithToken`, per-asset fees).
  - **Passkey sign-in** with Mera.
