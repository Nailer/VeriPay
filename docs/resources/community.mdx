## Getting help

| Need | Where |
|---|---|
| A problem with an order | The order's chat — an agent sees reported problems |
| A bug | GitHub issue |
| A security issue | [Responsible disclosure](/security/responsible-disclosure) |
| Exchange order help | The support chat on the exchange order page |
| Anything else | `support@veripay.store` |
